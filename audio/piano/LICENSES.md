# Pixeldate café piano (pd_piano_v01): licences and sources

Checked on **2026-10-30**. No CC-BY-SA, NC or unlicensed MIDI material was used, and no existing recordings of performances were used. All audio was synthesised note by note from a CC0 sample set with a custom Python sampler.

## Original pieces
*Steam on the Window*, *Sugar Cube Bossa* and *Moon in the Teacup* are new compositions (melody, harmony and arrangement) written for Pixeldate in October 2026. They contain no third-party material. The chord progressions use common jazz idioms (ii–V–I, tritone/backdoor colours), which are not copyrightable.

## Output files
The abridgements, performances and renderings in `dist/` were made for Pixeldate. Using them requires only the CC0 sample set (no attribution needed) and public-domain or original compositions.
